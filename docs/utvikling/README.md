# Utviklingsnotater for ShowCue

Samlet kunnskap om hvordan ShowCue er bygd, hvorfor ting er gjort som de er, og hva som er lært underveis.
Les dette før større endringer. Hold det oppdatert når noe viktig endres (samme PR som endringen).

| Fil | Innhold |
|---|---|
| [arkitektur.md](arkitektur.md) | Mapper, lydmotor, avspilling, video, fjernstyring, showfil og innstillinger på begge plattformer |
| [regler.md](regler.md) | Faste regler for kode, tekst, navn, språk og arbeidsflyt |
| [bygg-og-utgivelse.md](bygg-og-utgivelse.md) | CI, versjoner, utgivelser, pull requests og GitHub-oppsett |
| [testing.md](testing.md) | Testsett, stresstest og hvordan koden sjekkes uten Windows/Mac |
| [beslutninger.md](beslutninger.md) | Viktige valg og begrunnelsen, per versjon |
| [fallgruver.md](fallgruver.md) | Feil som er gjort eller funnet, og hvordan de unngås |
| [historikk.md](historikk.md) | Versjoner og pull requests |

Brukerdokumentasjonen står i `README.md` / `README.en.md` (rot, `Windows/`, `Mac/`) og `CHANGELOG.md` / `CHANGELOG.en.md`.
